# Contributing

You do not need to know git or GitHub to contribute. Pick whichever path fits.

## Option A — Just tell us (easiest)

Open an [issue](../../issues/new/choose) and pick a template:

- **Lesson learned** — describe what you built or bought, what happened, and what you'd do differently. A few paragraphs is plenty. A maintainer will turn it into a document and credit you (or keep you anonymous if you prefer).
- **Correction or question** — something is wrong, outdated, or unclear.
- **Template or resource** — you have a checklist, questionnaire, or policy outline others could reuse.

## Option B — Edit a file directly

1. Open the file on GitHub and click the pencil icon (top right of the file view).
2. Make your change.
3. Click **Commit changes**, then **Propose changes**. GitHub will create a pull request for review.

## Option C — Full pull request

Fork, branch, edit, open a PR. Standard workflow.

## Who can contribute

Trust companies and the people who work for them, sharing their own first-hand experience.

## What we ask of every contribution

- **No client data.** Ever. Not anonymised, not aggregated, not "just an example."
- **No proprietary code** unless you own it and are happy to release it under Apache 2.0.
- **Describe patterns, not anyone else's confidential material.** Your own experience is what's valuable.
- **Be candid.** The value of this repository is in the honest "what went wrong." Diplomatic vagueness helps nobody.
- **Date your facts.** Regulatory guidance, tools, and model behaviour change. Add a date when you state something that might.

## Style

- Plain English. Assume the reader is a smart trust officer, not an engineer.
- Diagrams in [Mermaid](https://mermaid.js.org/) inside the markdown so they render on GitHub and stay editable.
- Short sections, descriptive headings, bulleted lists over long paragraphs.

## Attribution

Contributors are listed in the document they contributed to unless they ask not to be. Firms can be named or described generically ("a mid-sized state-chartered trust company") — your choice.
